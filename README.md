
# 💅 Sistema de Agendamento - Salão de Manicure

## Sobre o projeto

Sistema desenvolvido em C++ para gerenciamento
de agendamentos de um salão de manicure.

O objetivo é facilitar o cadastro, a consulta,
a organização e o cancelamento de horários.

## Funcionalidades

- Cadastro de clientes e serviços.
- Agendamento por data e horário.
- Verificação de horários ocupados.
- Listagem de agendamentos.
- Busca por nome da cliente.
- Busca por data.
- Cancelamento por ID.
- Salvamento dos dados em arquivo CSV.

## Tecnologias utilizadas

- Linguagem C++
- Code::Blocks
- Biblioteca STL
- Arquivos CSV

## Conceitos de programação aplicados

- Struct
- Classes e objetos
- Vetores (vector)
- Funções e métodos
- Estruturas condicionais
- Laços de repetição
- Ordenação e busca
- Manipulação de arquivos

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo main.cpp no Code::Blocks.
3. Configure o compilador para C++11 ou superior.
4. Compile e execute o programa.
